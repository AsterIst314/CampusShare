# Project CampusShare
Website Pinjam Barang Antar Mahasiswa, platform web yang dirancang untuk memudahkan mahasiswa dalam meminjamkan, atau meminjam barang kebutuhan kuliah dan harian secara aman di lingkungan kampus. Website ini diharapkan mampu menghubungkan mahasiswa untuk saling meminjamkan kebutuhan akademis maupun harian seperti buku, alat elektronik, hingga perlengkapan acara secara efisien.
